# Tilting Maze Game 🌀

A fun and challenging tilting maze game where you control the maze by tilting it with a virtual joystick! 🎮

## 🎯 How to Play

- 🖱️ Click and drag the joystick to tilt the maze in different directions.
- 🎾 Guide all four balls to the center of the maze (the circular target).
- ⚠️ In hard mode, avoid falling into the black holes!
- 🏆 Win by getting all balls to the center without losing any.

## 🌟 Features

- 🕹️ Intuitive virtual joystick control with smooth animations.
- 🎨 Beautiful 3D tilting effect using CSS transforms.
- ⚫ Challenging black holes that appear in hard mode.
- 🔄 Physics-based ball movement with realistic collisions.
- 🎭 Easy and hard difficulty modes.
- ⌨️ Keyboard shortcuts for mode switching and reset.

## 🎮 Controls

- **Mouse**: Click and drag the joystick head to tilt the maze.
- **H Key**: Switch to hard mode (with black holes).
- **E Key**: Switch back to easy mode.
- **Spacebar**: Reset the game at any time.

## 🛠️ Technologies Used

- **HTML5**: Structure and canvas for the game elements.
- **CSS3**: Styling, animations, and 3D transforms.
- **JavaScript**: Game logic, physics, and user interactions.

## 🎨 Game Elements

- 🔴 **Balls**: The objects you need to guide to the center.
- 🟢 **Maze**: The playing field with walls and paths.
- 🕹️ **Joystick**: Your control mechanism for tilting.
- 🎯 **Center Target**: The goal area (dashed circle).
- ⚫ **Black Holes**: Dangerous areas in hard mode.

## 🏅 Tips for Success

- 🎯 Start slow and gentle with the joystick movements.
- 🔄 Use the walls to your advantage for bouncing balls.
- ⚡ Build momentum carefully in tight spaces.
- 👀 Watch all balls at once - they move independently!
